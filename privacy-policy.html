Key summary: VoltageDropVisualizer runs entirely on your local computer inside Autodesk Revit. It does not transmit your project data, electrical circuit data, or any personal information to any organization or any third-party server.

This Privacy Policy explains what information, if any, VoltageDropVisualizer ("the App") collects, how it is used, and your rights regarding that information. By installing and using the App you agree to the practices described here.

1. Data Collected by the App

The App reads data from your open Autodesk Revit project to perform its analysis. This data is processed exclusively in memory on your local workstation and is never transmitted to an external server.

Data Type How Collected Purpose Stored Externally?
Electrical circuit parameters (panel names, circuit numbers, load values, conductor sizes, voltages, lengths) Read from the active Revit model via the Revit API at analysis time Voltage drop calculation and colour-coding No — local only
Project name Read from the Revit document Displayed in the App header and included in exported reports No — local only
Exported report files (Excel / CSV) Written to a location you choose on your file system Saved only when you click Export Excel or Export CSV No — saved to your chosen path only
Crash / error logs Written locally by the .NET runtime when an unhandled exception occurs Debugging. Not automatically sent anywhere. No — local only

The App does not collect or transmit:

  • Your name, email address, or any other personal identification
  • Revit model geometry, drawings, or documents
  • IP addresses or location data
  • Usage telemetry, analytics events, or crash reports to any remote server
  • Login credentials of any kind

2. Third-Party Data Sharing

It does not share any data with third parties. Because the App operates entirely offline on your local workstation, no data originating from your Revit model or your computer reaches any external analytics platform, advertising network, or other third-party service.

The App uses the following open-source libraries, all of which execute locally and make no network calls:

  • Microsoft .NET runtime libraries — used for core application logic
  • Autodesk Revit API libraries — used to read Revit model data
  • ClosedXML / EPPlus (if applicable) — used for local Excel export

If a future version of the App introduces any third-party integration (e.g., cloud storage), this policy will be updated and users notified before the feature is activated.

3. Data Retention and Deletion

Since the App does not transmit or store your data on any organization's servers, there is no retention period applicable on our end.

  • In-memory data: All electrical circuit data is held in memory only for the duration of the App session. It is discarded immediately when you close the VoltageDropVisualizer window or close Revit.
  • Exported files: Excel or CSV reports are written to the file path you select. Any organization has no access to these files. You may delete them at any time.
  • Local error logs: If the .NET runtime writes an error log to your Windows user profile, you may delete this file manually. It is not sent anywhere automatically.

4. Revoking Consent and Requesting Data Deletion

Because it does not collect or hold any personal data from App users, there is nothing to delete on our servers. However, you may:

  • Stop using the App at any time by uninstalling it from your Revit add-ins folder (%AppData%\Autodesk\Revit\Addins\<version>\).
  • Delete any locally exported files (Excel / CSV reports) directly from your file system.
  • Contact us at dhaarani.nk@conservesolution.com if you have any questions about data handling. We will respond within 5 business days.

If we ever receive personal data (e.g., through a support email you send us), it will be used solely to respond to your enquiry and will not be shared with third parties. You may request deletion of such correspondence at any time by emailing us.

5. Children's Privacy

VoltageDropVisualizer is a professional engineering tool intended for adults working in the AEC (architecture, engineering, and construction) industry. We do not knowingly collect any information from individuals under the age of 16. If you believe a minor has inadvertently used the App, please contact us at dhaarani.nk@conservesolution.com.

6. Security

  • We recommend downloading the App only from the official Autodesk App Store.
